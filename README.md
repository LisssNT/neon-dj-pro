# NEON DJ PRO LAB — prototype 0.2.0

Современный браузерный DJ-инструмент с настоящим аудиодвижком. Приложение не является только визуальным макетом: декодирует и воспроизводит аудио, анализирует спектр в Web Worker, применяет EQ и эффекты к реальному аудиосигналу и смешивает два источника. Для ресурсоёмких моделей добавлен опциональный локальный Python API.

## Что реализовано

### Аудиодвижок в браузере
- Deck A / Deck B, локальная библиотека, воспроизведение, пауза, позиция трека и волновые формы.
- Мастер-громкость с динамическим компрессором на выходе; отдельная громкость деков.
- Трёхполосный EQ на каждом деке.
- Ручной кроссфейдер и автоматический переход между двумя треками.
- Режимы: Smart pick, equal-power crossfade, bass swap, filter sweep, echo out, phrase blend, beat cut и manual fader.
- Auto DJ: попытка подготовить следующий трек из библиотеки и запускать переход ближе к концу текущего трека.
- Без постоянной отправки аудио в облако: базовое декодирование и обработка происходят в браузере.

### Локальный DSP-анализ
- Оценка BPM через onset/tempo autocorrelation.
- Оценка тональности через chroma-профиль.
- Энергия, доля низких частот, спектральный центроид и onset density.
- Предварительная карта структуры по восьмисекундным окнам.
- Жанровая эвристика и рекомендации способа перехода по темпу, предполагаемой тональности, энергии и жанровой группе.
- Предложение примерных точек входа/выхода с использованием карты структуры и таймкодированных текстов.
- Загрузка текстов `.LRC`, `.SRT`, `.TXT`. Таймкодированные форматы могут учитываться при оценке пересечения вокала.

### Опциональный AI backend
- **Demucs** — фактическое разделение исходного трека на `vocals`, `drums`, `bass`, `other`; сервер дополнительно собирает `instrumental.wav` из трёх выровненных non-vocal stems.
- **faster-whisper** — распознавание вокального stem с примерными временными метками, если модель и зависимости доступны.
- **Genre classifier** — опциональная модель `dima806/music_genres_classification` дополняет DSP-эвристику широкой музыкальной категорией. Она обучена на GTZAN-классах и не должна считаться надёжным классификатором узких электронных поджанров.
- Файлы разделённых стемов сохраняются в `output/jobs/` и доступны из интерфейса для предварительного прослушивания в одном из деков.

## Важно о точности

Это расширенный MVP, а не законченный коммерческий AI-диджей. BPM, тональность, жанр и музыкальные секции — оценки: некоторые треки имеют half-time/double-time темп, неочевидную тональность, длинные интро или нестандартную структуру. Текущая локальная карта называет участки по акустическим признакам; она не гарантирует, что каждый участок действительно является куплетом, припевом или дропом. Для реального понимания музыкальной формы и текста нужна более специализированная крупная модель, более точная валидация на разной музыке и прослушивание результатов.

Сведение работает с реальным аудио, но текущая версия не выполняет полноценную beat-grid/downbeat-синхронизацию и не знает автоматически, что именно вокальная фраза закончилась на музыкально правильной доле. `Phrase blend` ожидает ближайшую границу расчётной четырёхдольной фразы; рекомендации по вокалу используют только таймкодированный текст, если он имеется.

## Быстрый запуск

Рекомендуется **Python 3.11**. Для декодирования разных форматов и Demucs установи FFmpeg и убедись, что команда `ffmpeg` доступна из терминала.

### Windows

1. Распакуй архив.
2. Открой PowerShell в папке проекта и выполни:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python server.py
```

3. Открой `http://127.0.0.1:8000` в Chrome, Edge или другом современном браузере.

Если Python 3.11 зарегистрирован в системе как `python`, но команда `py -3.11` недоступна, создай venv командой `python -m venv .venv`.

### macOS / Linux

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python server.py
```

Затем открой `http://127.0.0.1:8000`.

### Включить модели разделения и транскрипции

После установки базовых зависимостей выполни:

```bash
pip install -r requirements-ai.txt
```

Затем перезапусти `python server.py`. Первый запуск Demucs/Whisper/genre model может скачивать веса и занимать заметное время; для разделения аудио нужны дополнительные RAM/CPU или GPU. Если модель не установлена, основной аудиодвижок и локальный DSP остаются доступными, а интерфейс покажет доступность функций на сервере.

Переменные окружения (необязательно):

- `HOST=0.0.0.0` — разрешает подключение с других устройств в той же локальной сети. Используй только в доверенной сети и учитывай настройки firewall.
- `PORT=8000` — порт локального сервера.
- `NEON_DEMUCS_DEVICE=cpu` или `cuda` — устройство для Demucs, если соответствующая конфигурация PyTorch поддерживается.
- `NEON_DEMUCS_MODEL=htdemucs` — вариант модели Demucs.
- `NEON_WHISPER_MODEL=base` — размер модели Whisper (`tiny`, `base`, `small` и т. п.; более крупные модели требуют больше ресурсов).
- `NEON_WHISPER_DEVICE=cpu` и `NEON_WHISPER_COMPUTE_TYPE=int8` — параметры faster-whisper.
- `NEON_GENRE_MODEL=dima806/music_genres_classification` — модель широкой жанровой классификации.
- `NEON_MAX_UPLOAD_MB=200` — ограничение размера файла для backend.
- `NEON_MAX_ANALYZE_SECONDS=600` — предел длительности для серверного признакового анализа.
- `NEON_ALLOWED_ORIGINS` — список разрешённых браузерных origin через запятую; значение по умолчанию рассчитано на локальный запуск.

## Архитектура

```text
Browser UI (index.html)
 ├─ Web Audio API: two decks, EQ, compressor, gain graph, crossfader, FX
 ├─ static/analysis-worker.js: local FFT, onset envelope, BPM, chroma, spectral features
 ├─ transition logic: strategy recommendation, cue suggestions, Auto DJ
 └─ optional HTTP API
      └─ server.py (FastAPI)
          ├─ librosa: server-side feature analysis
          ├─ Demucs: vocal / drums / bass / other stems
          ├─ faster-whisper: transcript + timestamps
          └─ Transformers genre model (optional, broad labels)
```

## Приватность и данные

Импорт в браузере не отправляет музыку во внешнее облако. Кнопка **Deep AI / Separate stems + lyrics** отправляет выбранный файл в API, указанный в адресе сайта (при локальном запуске — на этот же компьютер). Сервер создаёт временную папку в `output/jobs/` и сохраняет отделённые WAV-файлы. Удаляй содержимое `output/jobs/`, когда результаты больше не нужны. Не загружай чужие аудиозаписи без соответствующих прав.

## Основные файлы

- `index.html` — интерфейс и аудиодвижок.
- `static/analysis-worker.js` — локальный DSP-анализ в Web Worker.
- `server.py` — локальный FastAPI API для тяжёлой обработки.
- `requirements.txt` / `requirements-base.txt` — базовые серверные зависимости.
- `requirements-ai.txt` — необязательные ресурсоёмкие AI-зависимости.

## Проверка проекта

В версии 0.2.0 выполнены синтаксические проверки JavaScript и Python и браузерная проверка базового потока: импорт WAV, вывод оценки BPM, назначение в два дека, EQ, переход и Stop. Полноценный end-to-end запуск Demucs и Whisper зависит от установки/загрузки весов и доступного оборудования; его нужно отдельно проверить на целевой машине.
